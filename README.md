# Sleep Deprivation and Cognitive Performance Analysis

## Opis projektu

Projekt analizuje zależność pomiędzy jakością i długością snu a funkcjami poznawczymi człowieka.

Analiza została wykonana przy użyciu języka Python oraz bibliotek do analizy danych i wizualizacji.

Projekt obejmuje:
- analizę danych,
- wizualizacje statystyczne,
- analizę korelacji,
- ocenę wpływu snu na koncentrację, stres i czas reakcji.

---

## Technologie

Projekt został wykonany przy użyciu:

- Python
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- seaborn
- scipy
- plotly

---

## Zbiór danych

Projekt wykorzystuje rzeczywisty zbiór danych dotyczący:
- jakości snu,
- poziomu stresu,
- aktywności fizycznej,
- czasu reakcji,
- funkcji poznawczych.

---

## Funkcjonalności projektu

Projekt zawiera:
- czyszczenie danych,
- analizę eksploracyjną (EDA),
- wizualizacje danych,
- heatmap korelacji,
- analizę statystyczną,
- wnioski końcowe.
