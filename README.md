# Sleep Analysis Project

## Opis projektu
Projekt analizuje wpływ snu na koncentrację (focus) oraz czas reakcji przy użyciu języka Python.

## Technologie
- Python
- pandas
- numpy
- matplotlib

## Jak uruchomić projekt

1. Pobierz projekt z GitHub (Download ZIP lub git clone)
2. Otwórz projekt w środowisku (np. Jupyter Notebook lub VS Code)
3. Upewnij się, że Python jest zainstalowany (zalecany Anaconda)
4. Zainstaluj wymagane biblioteki:
   pip install pandas numpy matplotlib
5. Uruchom plik analysis.py lub notebook w Jupyter
6. Wyniki oraz wykresy pojawią się automatycznie

## Cel projektu
Celem projektu jest zbadanie zależności pomiędzy długością snu, poziomem koncentracji oraz czasem reakcji przy użyciu analizy danych i wizualizacji.
